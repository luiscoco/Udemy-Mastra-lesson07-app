    01

    Define a minimal Agent

    Supply a stable id, display name, instructions and model. Add capabilities deliberately rather than starting with an opaque all-in-one configuration.

    02

    Export the definition

    The agent module exports the actual object used by the registry. Dead or unimported source is not a running component.

    03

    Register with Mastra

    The firstAgent registry key is how getAgent selects this agent. It differs from the stable lesson-seven-first-agent ID.

    04

    Use the correct lookup method

    getAgent resolves the registry key; getAgentById resolves the stable id. The lab executes those SDK methods instead of guessing from filenames.

    05

    Separate setup failures

    Registration can work while provider credentials or model permissions are missing. Inspect each boundary independently.

    06

    Run a bounded first task

    The optional live call uses the registered agent and a small prompt. It has explicit step, output and time limits.
